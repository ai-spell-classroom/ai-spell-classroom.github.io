## 二、第 15 頁尺寸（唯一必改）

### 問題根因

四條 `.qr45` 規則的層疊順序有誤：

```
(1) .qr45{width:45mm;height:45mm}                     基礎
(2) .exchange .xcard .qr45{height:54mm!important}     ← 新規則
(3) .qr45{width:44mm!important;height:54mm!important} ← 權重較低(0,0,1,0)
(4) .exchange .xcard .qr45{height:45mm!important}     ← 舊壓縮規則，殘留
```

(2) 與 (4) 同權重 (0,0,3,0) 且同為 `!important`，**後者勝**；(3) 權重較低無法覆蓋。結果：寬度取 (3) 的 44mm，高度取 (4) 的 **45mm**。

**Chromium print media 實測：** 四格皆 `44×45`（相對地，各實作頁的 `.personal .sticker` 五處皆正確渲染為 `44×54`）。

### 修法（已代為驗證，一行）

刪除或改寫第 (4) 條 → `.exchange .xcard .qr45{height:54mm!important}`。

**Claude 已在暫存副本實測此改法（未動交付檔）：**

| 項目 | 結果 |
| --- | --- |
| 四格尺寸 | `44×54` ×4 ✅ |
| 頁面高度 / 內容底緣 | 210 mm / **204.5 mm** |
| 版面餘裕 | **5.5 mm** |
| 溢出 | **無**（overflow: false）✅ |

→ **不需加頁、不需縮字、不需重排**，40 × 50 mm 貼紙貼上後四邊都有白邊。
