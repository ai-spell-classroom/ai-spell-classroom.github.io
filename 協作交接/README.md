## 協作方式

1. Codex 在「給 Claude」文件寫明審查目標、附檔、限制與問題。
2. Claude 直接在相對應的「給 Codex」文件寫回結論，不修改原始教材。
3. Codex 整合意見後，另存建議版本，交由 Tarshar 裁決。
4. 必須修改原檔或公開發布前，由 Tarshar 明確確認。
